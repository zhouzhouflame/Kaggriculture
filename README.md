# Kaggriculture：参赛记录与经营决策研究

这份记录整理 Kaggriculture 的参赛主控、全时域估值器、局部强化学习，以及从对局记录构建快照数据集的方法。

实际参赛时间为 9 天，最终提交的启发式 Agent 成绩为 **335 / 10,246，银牌**。参赛版本通过区域分工、完整任务链、状态检查和局部修复组织农场经营。

估值器与局部 RL 的联合方案在赛事截止后的后续实验中验证有效，项目记录中的后续对照相对参赛启发式版本取得 **10,745.8 游戏货币的期望资金优势**；然而非常遗憾的是受时间限制，该方案没有进入最终提交。

| 主题 | 核心问题 | 记录 |
